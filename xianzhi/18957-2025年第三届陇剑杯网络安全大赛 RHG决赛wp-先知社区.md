这是一个典型的**加密Web Shell**，其工作原理如下：

### 1. **密钥设置**

* `$k = "e10adc39"`：加密密钥（用于异或运算）。
* `$kh` 和 `$kf` 是用于匹配HTTP请求中加密数据的标记（开头和结尾）。
* `$p` 是输出响应时的前缀。

### 2. **加解密函数**

函数 `x($t, $k)` 是一个简单的**异或加密/解密函数**：

* 将输入字符串 `$t` 与密钥 `$k` 进行循环异或操作。
* 由于异或操作是对称的，同一个函数既可加密也可解密。

### 3. **Web Shell 逻辑**

* 监听 `php://input`（即HTTP POST请求的原始数据）。
* 使用正则表达式匹配 `$kh` 和 `$kf` 之间的内容（即加密的指令）。
* 对匹配到的内容（`$m[1]`）进行Base64解码，然后用密钥 `$k` 解密（通过异或函数 `x`），再解压缩（`gzuncompress`）。
* 通过 `eval()` 执行解密后的代码（这就是Web Shell的核心：任意代码执行）。
* 捕获输出（`ob_get_contents`），加密并压缩后，以Base64编码形式返回，并包裹在 `$p$kh...$kf` 中。

find\_the\_way`函数：

* 声明了局部变量：`v1`、`v2`、`buf[160]`（160字节的缓冲区）、`dest_`（指向未知类型的指针）。
* 程序提示输入一个整数`v1`（表示偏移），然后从`buf[v1]`处拷贝`sizeof(dest_)`（8字节，因为`dest_`是指针）到`dest_`变量。
* 然后读取最多0xA0（160）字节到`buf`中（这里存在栈溢出，因为`buf`大小为160，但可以读取160字节，但注意`buf`之后是其他变量，包括`dest_`）。
* 接着输入`v2`（另一个整数），计算`v2 + v1`（`v1`是之前输入的偏移，但注意`v1`在读取`buf`后可能被覆盖？实际上，`v1`是整数，在栈上位于`buf`之后）。
* 最后，将`buf[v2]`（即`buf`数组的索引为`v2`的位置）设置为0（空字节）。 解题：

1. **第一个输入（v1=0x80）**： c

```
memcpy(&dest_, &buf[v1], sizeof(dest_));
```

这里将`buf[0x80]`处的8字节拷贝到`dest_`。虽然代码中似乎没有直接使用`dest_`，但这个操作可能用于其他目的或者只是干扰。

2. **关键利用 - 控制返回地址**： c

```
buf[v2] = 0;  // v2 = input_v2 + strlen(buf)
```

通过控制`v2`的值，可以在`buf`数组的任意位置写入一个零字节。

3. **精心构造的payload**：

* `b'\x00'`：确保`strlen(buf)`返回0，这样`v2 = input_v2 + 0 = input_v2`
* `b'\x90' * 0x78`：NOP滑板，增加命中shellcode的几率
* `b'\x48\x81\xc4\x00\x10\x00\x00'`：调整RSP指针的指令（`add rsp, 0x1000`）
* `ShellcodeMall.amd64.execve_bin_sh`：执行/bin/sh的shellcode

4. **计算正确的偏移**：

* 发送`v2 = 0xA8`（168）

## boringRNG

代码里定义了一个 `RNG` 类，核心是一个 **LCG (Linear Congruential Generator, 线性同余生成器)**：  
![image.png](images/img_18957_027.png)

其中：

* M=2^n，这里 n=flag长度×8，所以模数是一个 2 的幂。
* A,C是大素数，题目输出了。
* 初始状态 S随机，但我们要恢复它。

加密方式：

![image.png](images/img_18957_028.png)

也就是每条消息 mi（flag 或随机数字串）与对应的 LCG 状态异或。

题目给了：

* M,A,CM, A, CM,A,C 的数值
* **5 条密文**：第 1 条是 flag，后 4 条是随机生成的 **十进制数字串（ASCII '0'..'9'）**

关键点：  
 随机消息 **只能包含数字字符**，这大大限制了解密结果的可能性。

根据模数是 2 的幂按字节逐步恢复就能解

def lift_S1(M, A, C, ciphers):
    cs = [bytes_to_long(c) for c in ciphers]
    candidates = [0]
    mod_k = 1
    for k in range(1, n+1):
        mod_k *= 256
        A_k, C_k = A % mod_k, C % mod_k
        new_cands = []
        for base in candidates:
            for b in range(256):
                S1 = base + (b << (8*(k-1)))
                S = S1
                ok = True
                for i, c in enumerate(cs):
                    m_low = (c ^ S) % mod_k
                    if i > 0:  # 4 个随机数消息必须是数字串
                        if any(not (0x30 <= bb <= 0x39) for bb in m_low.to_bytes(k, 'big')):
                            ok = False
                            break
                    S = (A_k*S + C_k) % mod_k
                if ok:
                    new_cands.append(S1)
        candidates = list(set(new_cands))
    return candidates[0]

def decrypt(M, A, C, ciphers, S1):
    states = []
    S = S1
    for _ in ciphers:
        states.append(S)
        S = (A*S + C) % M
    plains = []
    for c, s in zip(ciphers, states):
        m = bytes_to_long(c) ^ s
        plains.append(long_to_bytes(m, n))
    return plains

if __name__ == "__main__":
    S1 = lift_S1(M, A, C, ciphers)
    plains = decrypt(M, A, C, ciphers, S1)
    flag = plains[0].decode()
    print("flag:", flag)
    for i, p in enumerate(plains[1:], 1):

```
import re

logfile = "ezlog.log"
pattern = re.compile(r"vcan0\s+([0-9A-Fa-f]+)#([0-9A-Fa-f]+)")

# 保存每个 CANID 上一次的 payload
last_payload = {}
# 保存变化结果
changes = {}


def bytes_from_payload(payload):
    # 把payload按两个字符一组拆开成字节
    return [payload[i:i+2] for i in range(0, len(payload), 2)]


with open(logfile, "r") as f:
    for line in f:
        m = pattern.search(line)
        if not m:
            continue
        can_id, payload = m.groups()
        payload_bytes = bytes_from_payload(payload)

        if can_id not in last_payload:
            last_payload[can_id] = payload_bytes
            continue

        prev = last_payload[can_id]
        # 长度可能不一样，补齐
        length = min(len(prev), len(payload_bytes))
        diff_bytes = []
        for i in range(length):
            if prev[i] != payload_bytes[i]:
                diff_bytes.append(payload_bytes[i])

        if diff_bytes:
            if can_id not in changes:
                changes[can_id] = []
            changes[can_id].extend(diff_bytes)

        last_payload[can_id] = payload_bytes

# 输出结果
for can_id, vals in changes.items():
    print(f"{can_id}: {' '.join(vals)}")
    #保存到文件夹output中
    with open(f"output/{can_id}.txt", "w") as f:
        f.write(" ".join(vals))

输出文件 `output.txt` 包含一个列表，每个元素是三元组 `(a, x, y)`，其中：

* `a = (n * P).x * m % p`
* `(x, y)` 是点 `n * G` 的坐标

这里：

* `G` 是曲线基点
* `P` 是公钥（随机生成的点）
* `n` 是随机起始值和一个随机步长生成的等差数列：`n_i = start + i * step`，其中 `start` 和 `step` 是 `[0, q-1]` 的随机数
* `m` 是flag的每个字节

我们需要恢复 `m`（即flag）。

1. **利用flag格式**：flag通常以 `flag{` 开头，因此前5个字节已知（`f`, `l`, `a`, `g`, `{`）。
2. 对于前5个点（i=0,1,2,3,4），我们可以计算：

* `(n_i * P).x = a_i * inv(m_i, p) % p`

#!/usr/bin/env python3
"""
arnold_bruteforce.py

对经过 Arnold 猫脸变换处理的图像进行逆变换（解密）。
自动尝试 a, b, iterations 在 20~29 范围内的所有组合。

用法:
    python arnold_bruteforce.py flag.png

输出:
    在 output/ 子目录下生成大量解密结果文件，文件名格式为:
        decrypted_a{a}_b{b}_i{iter}.png
"""

import sys
import os
from PIL import Image
import numpy as np

def inverse_arnold_map_coords(N, a, b):
    M_inv = np.array([[a * b + 1, -a], [-b, 1]], dtype=np.int64)
    return M_inv % N

def decrypt_image(img_arr, a, b, iterations):
    N = img_arr.shape[0]
    xs, ys = np.meshgrid(np.arange(N, dtype=np.int64), np.arange(N, dtype=np.int64))
    coords = np.stack([xs, ys], axis=0).reshape(2, -1)
    out = img_arr.copy()
    for _ in range(iterations):
        M_inv = inverse_arnold_map_coords(N, a, b)
        new_coords = (M_inv.dot(coords)) % N
        x_new = new_coords[0].reshape(N, N)
        y_new = new_coords[1].reshape(N, N)
        decrypted = np.zeros_like(out)
        if out.ndim == 2:
            decrypted[x_new, y_new] = out[xs, ys]
        else:
            decrypted[x_new, y_new, :] = out[xs, ys, :]
        out = decrypted
    return out

def center_crop_to_square(im: Image.Image) -> Image.Image:
    w, h = im.size
    if w == h:
        return im
    N = min(w, h)
    left = (w - N) // 2
    top = (h - N) // 2
    return im.crop((left, top, left + N, top + N))

def main(argv):
    if len(argv) != 1:
        print("用法: python arnold_bruteforce.py flag.png")
        return 1

    input_path = argv[0]
    im = Image.open(input_path).convert('RGBA')
    im = center_crop_to_square(im)
    arr = np.array(im)
    N = arr.shape[0]
    print(f"输入图像大小: {N}x{N}")

    os.makedirs("output", exist_ok=True)

    for a in range(20,30):
        for b in range(20,30):
            for it in range(20,30):
                decrypted_arr = decrypt_image(arr, a, b, it)
                out_im = Image.fromarray(decrypted_arr)
                out_path = f"output/decrypted_a{a}_b{b}_i{it}.png"
                out_im.save(out_path)
                print(f"保存 {out_path}")

    print("所有组合完成，结果保存在 output/ 目录。")
    return 0

if __name__ == '__main__':
    sys.exit(main(sys.argv[1:]))

USER_KEYS = ["Login Details", "ID", "Username", "USER_LOGIN"]
PASS_KEYS = ["password", "KEY", "Password", "USER_PASS"]

def extract_smtp_credentials(pcap_file, user_file="user.txt", passwd_file="passwd.txt"):
    packets = rdpcap(pcap_file)
    users, passwords = [], []

    for pkt in packets:
        if pkt.haslayer(Raw):
            try:
                payload = pkt[Raw].load.decode(errors="ignore")
            except:
                continue

            lines = [l.strip() for l in payload.splitlines() if l.strip()]
            for i in range(len(lines) - 1):
                line1, line2 = lines[i], lines[i+1]

                # 检测用户名行
                if any(k in line1 for k in USER_KEYS) and any(k in line2 for k in PASS_KEYS):
                    # 清理符号
                    clean_user = re.sub(r"[:=]", " ", line1).split()[-1]
                    clean_pass = re.sub(r"[:=]", " ", line2).split()[-1]
                    users.append(clean_user)
                    passwords.append(clean_pass)

    # 保存
    with open(user_file, "w") as uf, open(passwd_file, "w") as pf:
        uf.write(",".join(users) + ",")
        pf.write(",".join(passwords) + ",")

    print(f"[+] 提取完成，共找到 {len(users)} 组账号/密码")

if __name__ == "__main__":

这个题目是一个典型的堆利用挑战，结合了格式化字符串漏洞和栈溢出来最终获取系统shell。以下是详细的解释

1. **程序功能**：

* 程序模拟了一个“死亡笔记”的菜单，允许用户写入名字（分配堆块）、删除名字（释放堆块）、查看名字（读取堆块内容）以及使用“死亡之笔”（特殊功能）。
* 特殊选项`114514`可以调用`Death_s_Pen()`函数，该函数在特定条件下允许分配大块内存。

1. **漏洞点**：

* **格式化字符串漏洞**：在`show_name()`函数中，当用户查看一个名字时，程序使用`write(1, *ptr, size)`输出内容。但如果用户能够控制`size`和内容，就可以泄露栈上的信息（如canary、libc地址等）。
* **堆溢出**：在`Death_s_Pen()`函数中，程序会分配多个0x60大小的堆块，然后允许用户分配一个最大4096字节的堆块。如果用户分配一个较大的块并写入过多数据，可能覆盖相邻堆块的管理结构，但本题中未直接利用堆溢出。
* **栈溢出**：在`Death_s_Pen()`函数中，用户分配一个大块后，程序读取用户输入时使用`read(0, *ptr, size)`，但并没有检查边界。如果用户分配的大小接近或超过某个临界值，可能覆盖栈上的返回地址。

1. **利用思路**：

* **信息泄露**：首先利用格式化字符串漏洞泄露canary、代码基地址和libc基地址。

* 通过提交一篇文章（选项1）并包含特定payload（如重复的特定字节）来准备堆内容。
* 然后通过选项2触发格式化字符串漏洞（通过提交负值数量？但实际代码中未直接显示，可能是通过其他方式触发）。
* 实际上，在`show_name()`中输出内容时，如果内容包含格式化字符串（如`%p`），可以泄露栈上的值。

* Payload结构：填充字节（0x408） + canary（覆盖栈保护值） + 填充（8字节） + ROP链（`pop rdi; ret` + `/bin/sh`地址 + `system`地址）。

### 解题步骤详解

1. **泄露关键信息**：

* 首先选择选项1写入一篇文章，内容为特定pattern（如`(p32(0x3B) + p32(0x17)) * (0x500 // 8)`），目的是在堆上布置数据，以便后续通过格式化字符串读取。
* 然后选择选项2（删除？但实际代码中选项2是删除，这里可能是误用，实际应通过选项3查看来触发格式化字符串）。

* 更直接的方式：通过选项3（查看名字）来触发格式化字符串漏洞。当查看一个名字时，如果该名字的内容包含`%p`等格式化符，程序会输出栈上的值。
* 在解题代码中，通过`show_name()`输出内容时，使用`%6$p#%9$p#%131$p#`来泄露：

* `%6$p`：泄露栈上的某个值（可能是代码地址）。
* `%9$p`：泄露canary。
* `%131$p`：泄露libc地址。

* 从泄露的值计算基地址：

* 代码基地址 = 泄露的代码地址 - 0x18E0（偏移）。
* libc基地址 = 泄露的libc地址 - 0x90E93（偏移）。

1. **栈溢出攻击**：

* 前0x408字节为填充（如'a'）。
* 然后覆盖canary（使用泄露的canary值，以绕过栈保护）。
* 再覆盖8字节的填充（覆盖旧的rbp）。
* 最后构造ROP链：

* `ret`指令（用于栈对齐）。
* `pop rdi; ret`（将`/bin/sh`字符串地址放入rdi）。

import re
import hashlib

def extract_data(text):
    # 定义四种数据的正则表达式模式
    email_pattern = r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b'
    ip_pattern = r'\b(?:\d{1,3}\.){3}\d{1,3}\b'
    phone_pattern = r'\b\d{11,15}\b'  # 11-15位数字
    long_digit_pattern = r'\b\d{15,18}\b'  # 15-18位长数字
    
    # 提取四种数据
    emails = re.findall(email_pattern, text)
    ips = re.findall(ip_pattern, text)
    phones = re.findall(phone_pattern, text)
    long_digits = re.findall(long_digit_pattern, text)
    
    return emails, ips, phones, long_digits

def calculate_md5(data_list):
    """将列表中的数据用逗号连接后计算MD5"""
    if not data_list:
        return hashlib.md5("".encode()).hexdigest()
    
    combined = ",".join(data_list)
    return hashlib.md5(combined.encode()).hexdigest()

def main():
    # 读取文件
    with open('mixed_sensitive_data.txt', 'r', encoding='utf-8') as file:
        content = file.read()
    
    # 提取四种数据
    emails, ips, phones, long_digits = extract_data(content)
    
    print("提取到的数据:")
    print(f"Emails: {emails}")
    print(f"IPs: {ips}")
    print(f"Phones: {phones}")
    print(f"Long digits: {long_digits}")
    
    # 计算每种数据的MD5
    email_md5 = calculate_md5(emails)
    ip_md5 = calculate_md5(ips)
    phone_md5 = calculate_md5(phones)
    long_digit_md5 = calculate_md5(long_digits)
    
    print("
各类型数据的MD5:")
    print(f"Emails MD5: {email_md5}")
    print(f"IPs MD5: {ip_md5}")
    print(f"Phones MD5: {phone_md5}")
    print(f"Long digits MD5: {long_digit_md5}")
    
    # 连接四种MD5并再次计算MD5
    combined_md5 = email_md5 + ip_md5 + phone_md5 + long_digit_md5
    final_md5 = hashlib.md5(combined_md5.encode()).hexdigest()
    
    print(f"
最终Flag: flag{{{final_md5}}}")

if __name__ == "__main__":
    main()
```
