这里也写的很清晰，首先在HashSet中加入几个特征，然后在下文的doFilter中判断是否存在用户的session如果不存在并且访问的路由中包含以上几个特征，就抛出一个异常，然后catch到后返回登录页面。

### 四、功能点反射调用分析

我们来分析下`com.artery.form.FormService`。这是这套源码中最特别的地方，这套源码审计的核心也在这里。

这个FormService本质是一个Servlet，负责接收前端表单相关的请求，通过反射动态定位并调用后端服务类的方法，最终将结果以XML格式返回给前端。它是前端与后端服务之间的“中间层”。

首先是定义内容类型常量：

![image.png](images/20250910160111-50fc593a-8e1c-1.png)  
这里其实就是声明了几个常量，并且定义了几个Map用来存在下面反射调用拿到的方法并存储起来的。

从plugins.xml中读取配置：  
![image.png](images/20250910160112-51397586-8e1c-1.png)  
![image.png](images/20250910160113-51dcc042-8e1c-1.png)  
![image.png](images/20250910160114-52b82bdc-8e1c-1.png)  
下面这段代码是核心，我不截图了，直接复制过来的：

```
public static Object[] getService(HttpServletRequest request, String serviceName) throws Exception {
    if (serviceName != null && serviceName.length() != 0) {  // 校验服务名非空
        Object[] result = (Object[])serviceMap.get(serviceName);  // 先查缓存，命中则直接返回
        if (result != null) {
            return result;
        } else {
            // 缓存未命中，解析服务名并反射获取服务信息
            Class serviceClass = null;  // 服务类
            String serviceGroupName = null;  // 服务组名（如"attachment"）
            String methodName = null;  // 方法名（如"getAttachementItem"）
            Method method = null;  // 目标方法
            Class paramType = null;  // 方法的第三个参数类型（若有）

            int dotPos = serviceName.indexOf(46);  // 查找服务名中的"."（46是ASCII的"."）
            if (dotPos == -1) {  // 服务名无"."（如"getForm"），默认使用FormServiceImpl类
                serviceClass = FormServiceImpl.class;
                serviceGroupName = "service";
                methodName = serviceName;
            } else {  // 服务名有"."（如"attachment.getAttachementItem"）
                serviceGroupName = serviceName.substring(0, dotPos);  // 截取服务组名（如"attachment"）
                if (!pluginMap.containsKey(serviceGroupName)) {  // 校验服务组是否在插件配置中
                    throw new Exception(LocalMessage.getInstance(request).getMessage("formservice.error.serviceNotExist", new Object[]{serviceName}));
                }
                // 从插件配置获取服务类全路径，反射加载类
                serviceClass = Class.forName((String)pluginMap.get(serviceGroupName));
                methodName = serviceName.substring(dotPos + 1);  // 截取方法名（如"getAttachementItem"）
            }

            // 从缓存获取服务类的方法数组（未缓存则反射获取并缓存）
            Method[] methods = (Method[])methodsMap.get(serviceClass);
            if (methods == null) {
                methods = serviceClass.getMethods();  // 反射获取类的所有公共方法
                methodsMap.put(serviceClass, methods);  // 缓存到methodsMap
            }

            // 遍历方法数组，找到目标方法（按方法名匹配）
            int i;
            if (!AbstractArteryService.class.isAssignableFrom(serviceClass)) {  // 非AbstractArteryService子类
                for(i = 0; i < methods.length; ++i) {
                    if (methods[i].getName().equals(methodName)) {  // 匹配方法名
                        method = methods[i];
                        Class[] types = method.getParameterTypes();  // 获取方法参数类型
                        if (types.length == 3) {  // 若方法有3个参数，第三个参数为内容参数
                            paramType = types[2];
                        } else {
                            if (types.length != 2) {  // 非2个或3个参数，抛出"方法不存在"异常
                                throw new Exception(LocalMessage.getInstance(request).getMessage("formservice.error.methodNotExist", new Object[]{serviceName, methodName}));
                            }
                            paramType = null;  // 2个参数（request, response），无内容参数
                        }
                        break;
                    }
                }
            } else {  // 是AbstractArteryService子类（自定义服务基类）
                for(i = 0; i < methods.length; ++i) {
            if (methods[i].getName().equals(methodName)) {  // 匹配方法名
            method = methods[i];
            break;
        }
        }
            paramType = AbstractArteryService.class;  // 标记为自定义服务类型
        }

            if (method == null) {  // 未找到目标方法，抛出异常
            throw new Exception(LocalMessage.getInstance(request).getMessage("formservice.error.methodNotExist", new Object[]{serviceName, methodName}));
        } else {
            // 根据paramType确定内容类型（CONTENT_TYPE_XXX）
            byte contentType;
            if (paramType == null) {
            contentType = 0;  // 无内容参数
        } else if (paramType == String.class) {
            contentType = 2;  // 字符串
        } else if (paramType == Document.class) {
            contentType = 1;  // XML
        } else if (paramType == JSONObject.class) {
            contentType = 3;  // JSON对象
        } else if (paramType == JSONArray.class) {
            contentType = 4;  // JSON数组
        } else if (paramType == InputStream.class) {
            contentType = 5;  // 流
        } else if (paramType == AbstractArteryService.class) {
            contentType = 6;  // 自定义服务对象
        } else {
            contentType = 7;  // JavaBean
        }

            // 封装服务信息（服务类、方法、内容类型、服务组、方法名）并缓存
            result = new Object[]{serviceClass, method, new Integer(contentType), serviceGroupName, methodName};
            serviceMap.put(serviceName, result);
            return result;
        }
        }
        } else {
            throw new Exception(LocalMessage.getInstance(request).getMessage("formservice.error.invalidRequest"));  // 服务名为空，抛出无效请求异常
        }
        }
```

核心作用在于通过服务名解析服务组和方法名，反射获取目标方法，确定参数类型，并缓存结果。

下面是关键的服务调用鉴权方式，审计前台洞的核心在这：  
![](images/20260326212822-a97e86f2-2917-1.png)

从service参数中拿到服务名，通过反射调用判断方法中是否存在`isAccessible`方法。

这里的`isAccessible`方法实际上就是判断该方法是否可以匿名访问的方法。

![image.png](images/20250910160115-532758c2-8e1c-1.png)

需要注意的是，这段代码通过反射调用拿到的方法必须是public。

此外，还有一个点要知道的，通过FormService类去实现服务调用，用户输入是可以通过一个参数`content`来接收的，并且这里content-type的不同，就会走不同逻辑，利用的方式也就不尽相同，这个后文再重点说下。

![image.png](images/20250910160116-541415cc-8e1c-1.png)

那下面我们就有操作空间了——无`isAccessible`方法+sink函数为public。

#### 2、com.artery.form.services.FormStudioUpdater#getStudioFile任意文件读取

在这个类下面，不存在web.xml定义的路由了，因此我们首先重点关注下，是否存在相应的鉴权的方法，如果没有我们就可以通过FormService类反射调用到这个类中的一些公共方法。

往下看，找到一处sink点，该处getStudioFile方法，可从前端接收Http请求，并且接收fileStr参数，并对fileStr进行文件读取。
