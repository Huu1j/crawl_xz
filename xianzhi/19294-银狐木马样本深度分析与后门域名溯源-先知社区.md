## 六、安全处置建议

### 6.1 紧急处置措施

* **域名拦截**：企业及个人用户可在防火墙、DNS 服务器中添加后门域名黑名单，阻断与 yk.ggdy.com 等相关域名的连接。
* **IP 封禁**：在网络边界设备中封禁关联的恶意 IP 地址（115.190.102.32 等），防止内网设备与 C2 服务器通信。
* **样本清除**：已感染设备需立即终止木马进程（进程名：XX.exe），删除 C:UsersPublicDocumentssys\_update.dat 恶意文件，清除注册表自启项(HKEY\_LOCAL\_MACHINESOFTWARE,HKEY\_CURRENT\_USERConsole)，并用杀毒软件进行全盘扫描。

### 6.2 长期防护策略

* **加强终端安全**：定期更新操作系统与应用软件补丁，安装正规杀毒软件并开启实时防护，避免点击来历不明的邮件附件与链接。
* **强化域名与 IP 管控**：企业可部署 DNS 安全防护系统，实时拦截恶意域名解析；通过威胁情报平台同步最新恶意 IP 与域名列表，动态更新防护规则。
* **提升安全监测能力**：部署网络流量监测、终端行为审计等工具，及时发现异常网络连接、未知进程启动等恶意行为，实现 “早发现、早处置”。

### 补充：代理

我们这里再补充一下代理的概念吧，也是溯源比较重要的一个知识点，溯源还是像我现在科学上网到日本的IP了，然后如果别人要溯源你的IP的话就要通过这个IP代理商去溯源去溯源你的IP

![f6a8b37b11dfdc2f49f201cf28e98cb5.jpg](images/img_19294_013.png)

能否通过这个代理 IP 溯源到你的真实 IP，取决于 3 个关键因素也分代理类型、代理服务商是否留存日志、溯源方的权限

像个人没有执法权的话几乎不可能溯源到你他们只能获取到你暴露的「日本代理 IP」，无法进一步溯源他们没有权限要求代理服务商提供日志；看不到你真实的网络出口 IP（你的运营商分配的公网 IP）；最多只能查到这个日本代理 IP 的归属地（如日本东京某机房），但查不到你本人

有执法权的机构（网安、警方、国际执法部门）→ 大概率能溯源到真实 IP如果是因违法违规行为（如网络攻击、传播违禁内容）被溯源，执法机构有能力穿透代理，找到你的真实 IP：执法机构会向「日本代理服务商」出具执法文书，要求提供代理日志（包括：你的真实 IP、使用代理的时间、代理 IP 的分配记录等）；代理服务商若留存了日志，执法机构就能通过日志关联到你的真实 IP（你的运营商分配的公网 IP）；再通过你的真实 IP，联系国内运营商查询该 IP 的开户人信息（姓名、身份证、地址等），最终定位到你。

国内合规的 VPN 服务商（用于企业办公等合法场景）必须留存日志，且需配合执法；国外部分 “无日志” 代理，若服务器位于有执法协作的国家（如美、日、欧盟），也可能被要求提供数据。

​

|  |  |  |
| --- | --- | --- |
| 工具类型 | 匿名性 | 能否溯源核心点 |
| 免费公共代理（HTTP/SOCKS） | 极低（透明 / 匿名代理） | 1. 可能泄露真实 IP（透明代理会在请求头带真实 IP）；2. 大多留存日志，且易被监控； |
| 付费普通 VPN | 中等（高匿代理） | 1. 不泄露真实 IP，但服务商大概率留存日志（国内 / 国外合规服务商均需配合执法）； |
| 无日志 VPN / 代理（需验证） | 较高（但非绝对） | 1. 宣称 “不留存日志”，但需确认是否真的无日志（部分商家虚假宣传）；2. 若真无日志，执法机构也无法获取关联信息； |
| Tor 浏览器（多节点转发） | 极高（层层加密转发） | 1. 真实 IP 被多层节点隐藏，单个节点无法关联你的真实 IP；2. 但仍可能因操作失误（如泄露真实信息）被溯源； |

​

挂了代理也容易泄露IP的方式

1.DNS 泄露：部分代理只转发 HTTP/HTTPS 流量，不转发 DNS 查询，你的 DNS 请求会直接用本地网络发送，暴露真实 IP；

2.WebRTC 泄露：浏览器的 WebRTC 功能会直接暴露你的真实公网 IP（之前查公网 IP 时提到过），和代理 IP 无关；

3.操作失误：比如用代理访问时，同时登录了绑定真实信息的账号（微信、支付宝、手机号），即使 IP 是日本的，也能通过账号信息定位到你；

4.代理工具本身有漏洞：部分免费 / 破解版代理工具可能内置后门，直接上传你的真实 IP 和设备信息。
